# ช่วงแคตต้าบอกรัก
แด่นายท่านทุกคนที่แนะนำแนวทางให้แคตต้าปรับปรุงให้ดือขึ้น!
- สำคัญมาก ขอบคุณคูม Kong ที่ชี้นำแนะนำแนวทางเหล่าโนมให้พัฒนาแคตต้าเจ๋งขึ้นนะฮะ แคตต้าเฮฟเซฟตี้ แคตต้ารักคูม Kong !!
- ขอบคุงคูมมอสและคูมเมลบีที่เสนอเรื่อง ปุ่มกลมๆ แคตต้าลอยให้จาง มันดือมากๆ! สบายตาสุดๆ ! ขอบคุณเรื่องแนะนำเรื่องจดจำโทเค้นเพลย์ไว้กับเครื่องด้วยนะครับ สะดวกกับนายท่านของแคตต้ามากเลย !
- และขอบคุณนายท่านทุกๆคนที่เสนอไอเดียมากมาย เพื่อปรับปรุงแคตต้าให่เป็นส่วนเสริมที่น่ารักที่สุด หากนายท่าน อยากแนะนำอะไรเพิ่ม แจ้งทีมงานโนมได้เลยนะฮะ!! แคตต้ารอ แคตต้ารัก!!
